# 🖥️ PC Minimal Monitor v1.0
**by SantaNyb**

Лёгкий и минималистичный системный монитор для Windows 10/11 (x64), написанный на C# (.NET 8) с использованием библиотеки `LibreHardwareMonitorLib`. Работает в одном автономном Portable-файле без установки.

---

## ✨ Возможности
* **Точные датчики процессора и видеокарты:** отображение температуры ядер (`CCD1 / Tdie` для AMD Ryzen и `Package / Core` для Intel), частоты (МГц), энергопотребления (Вт) и видеопамяти (VRAM).
* **Фиксация пиков:** автоматический подсчёт максимальной температуры за сессию (`Макс: XX°C`) и динамическая смена цвета при нагреве.
* **ОЗУ и прожорливые процессы:** объём занятой памяти, температура DDR5 (при наличии датчика) и отображение процессов, сильнее всего нагружающих CPU и ОЗУ.
* **Вкладки:**
  * `Главное` — живые графики CPU, GPU и карточка ОЗУ.
  * `Диски` — температура и активность накопителей SSD / NVMe M.2.
  * `Кулеры` — обороты вентиляторов (RPM и %).
  * `Система и Сеть` — скорость скачивания/отдачи интернета в реальном времени, аптайм ПК и статус питания.
* **Игровой оверлей (`Alt + H`):** компактный HUD поверх оконных игр с выбором позиции (4 угла или свободное перетаскивание мышью), цвета шрифта, размера и режима фона.
* **Удобство:** сворачивание в системный трей, автозапуск вместе с Windows, 3 темы оформления и автосохранение настроек.

---

## 📥 Как скачать и запустить
1. Перейдите в раздел **[Релизы (Releases)](../../releases)** в правой колонке и скачайте архив **`PC-Minimal-Monitor-v1.0.zip`**.
2. Распакуйте `PcMonitor.exe` в любую удобную папку и запустите.
3. При первом запуске Windows SmartScreen может показать предупреждение — нажмите **«Подробнее» -> «Выполнить в любом случае»**.

## 🛠 Сборка из исходников
Требуется установленный **.NET 8 SDK** (Windows):
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```
